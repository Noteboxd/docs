Noteboxd is a REST API that gives developers structured, queryable access to a deep catalog of fragrance data — including fragrances, brands, perfumers, notes, accords, and charts. Whether you're building a scent discovery app, enriching a product catalog, powering recommendation features, or analyzing fragrance trends, Noteboxd provides the data layer you need. It's designed to be simple to integrate, transparent to price, and reliable at any scale.

## What you'll need

Before making your first API call, make sure you have the following:

- **A Noteboxd developer account** — sign up or sign in at [developers.noteboxd.com](https://developers.noteboxd.com).
- **A project API key** — keys are scoped to projects and are prefixed `nb_live_`. You can create a project and copy your key from the Keys section of the developer dashboard.
- **A prepaid balance** — Noteboxd is billed pay-per-call. You'll need to add a balance from the Billing section before your requests will succeed. Calls cost between 1¢ and 25¢ each depending on the endpoint.
