Notes are the olfactory ingredients used to describe a fragrance — bergamot, oud, rose, sandalwood, vetiver. This endpoint returns a bounded list you can filter by family and sort by popularity or name. It does not accept `page`, and it does not walk the entire note catalogue.

## Endpoint

```
GET /v1/notes
```

**Base URL:** `https://api.noteboxd.com`  
**Cost:** 1¢ per call  
**Authentication:** `Authorization: Bearer nb_live_YOUR_KEY`

## Query Parameters

<ParamField query="family" type="string">
  Optional family filter, for example `woody` or `floral`.
</ParamField>

<ParamField query="sort" type="string" default="popular">
  `popular` or `name`.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  How many notes to return. Integer from `1` to `50`.
</ParamField>

## Example Request

```bash
curl -G https://api.noteboxd.com/v1/notes \
  -H "Authorization: Bearer nb_live_YOUR_KEY" \
  --data-urlencode "family=woody" \
  --data-urlencode "sort=popular" \
  --data-urlencode "limit=20"
```

## Example Response

```json
{
  "data": [
    { "slug": "oud", "name": "Oud", "family": "Woody" },
    { "slug": "sandalwood", "name": "Sandalwood", "family": "Woody" },
    { "slug": "vetiver", "name": "Vetiver", "family": "Woody" }
  ]
}
```

<Tip>
  Pass a note `slug` to `GET /v1/notes/{slug}` for its profile and the fragrances that feature it.
</Tip>

## Rate Limiting

Every response includes the following headers to help you track your usage:

| Header | Description |
|---|---|
| `X-RateLimit-Limit` | Total requests allowed in the current window |
| `X-RateLimit-Remaining` | Requests remaining before you hit the limit |
| `X-RateLimit-Reset` | Unix timestamp when the window resets |
