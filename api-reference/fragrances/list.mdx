The **List Fragrances** endpoint returns a paginated catalogue of every fragrance in the Noteboxd database. Each item in the response is a fragrance summary containing the unique ID, name, and brand — ideal for building browse interfaces, populating dropdowns, or syncing your local catalogue. Use the `page` and `limit` parameters to walk through the full dataset at your own pace.

## Endpoint

```
GET /v1/fragrances
```

**Cost:** 1¢ per call

## Query Parameters

<ParamField query="page" type="integer" required default="1">
  The page number to retrieve. Must be greater than or equal to `1`.
</ParamField>

<ParamField query="limit" type="integer" required default="20">
  The number of fragrance summaries to return per page. Must be between `1` and `50` inclusive.
</ParamField>

## Example Request

```bash
curl -G https://api.noteboxd.com/v1/fragrances \
  -H "Authorization: Bearer nb_live_YOUR_KEY" \
  --data-urlencode "page=1" \
  --data-urlencode "limit=20"
```

## Example Response

```json
{
  "data": [
    { "id": "chanel-no-5", "name": "No 5", "brand": "Chanel" },
    { "id": "dior-sauvage", "name": "Sauvage", "brand": "Dior" }
  ],
  "pagination": {
    "page": 1,
    "limit": 20,
    "total": 45820
  }
}
```

## Response Fields

| Field | Type | Description |
|---|---|---|
| `data` | array | Array of fragrance summary objects for the requested page. |
| `data[].id` | string | Unique fragrance identifier. Use this ID with other fragrance endpoints. |
| `data[].name` | string | Display name of the fragrance. |
| `data[].brand` | string | Brand or house that produces the fragrance. |
| `pagination.page` | integer | The current page number returned. |
| `pagination.limit` | integer | The number of items per page used for this request. |
| `pagination.total` | integer | Total number of fragrances across all pages. |

## Rate Limit Headers

Every response includes the following headers:

| Header | Description |
|---|---|
| `X-RateLimit-Limit` | Maximum number of requests allowed in the current window. |
| `X-RateLimit-Remaining` | Number of requests remaining in the current window. |
| `X-RateLimit-Reset` | Unix timestamp at which the rate limit window resets. |

<Note>
  This endpoint returns lightweight summary objects only. To retrieve full fragrance details — including notes, accords, and perfumer attribution — pass the `id` to [Get Fragrance](/api-reference/fragrances/get).
</Note>

<Tip>
  If you need keyword-based filtering rather than full catalogue pagination, use the `/v1/search` endpoint instead. It supports full-text queries against fragrance names, brands, and notes.
</Tip>
