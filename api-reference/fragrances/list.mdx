`GET /v1/fragrances` searches and filters the fragrance catalogue. It does not return the full catalogue page by page. Send at least one filter — `q`, `brand`, `note`, `family`, or `priceRange` — or the API responds with `400 INVALID_QUERY`. Walk a large result set by passing the previous response's `nextCursor` as `cursor`.

For every fragrance from one house, use [List brand fragrances](/api-reference/brands/fragrances), which is page-numbered. For a keyword lookup across entity types, use [Search](/api-reference/search/search).

## Endpoint

```
GET /v1/fragrances
```

**Cost:** 1¢ per call

## Query Parameters

<ParamField query="q" type="string">
  Free text matched against fragrance and brand names. 1–100 characters.
</ParamField>

<ParamField query="brand" type="string">
  Brand slug, for example `chanel`.
</ParamField>

<ParamField query="note" type="string">
  Note slug, for example `oud`.
</ParamField>

<ParamField query="family" type="string">
  Olfactory family, for example `woody`.
</ParamField>

<ParamField query="priceRange" type="string">
  One of `BUDGET`, `MIDRANGE`, or `PREMIUM`.
</ParamField>

<ParamField query="cursor" type="string">
  Cursor from the previous response's `nextCursor`. Omit it for the first page.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Page size. Integer from `1` to `50`.
</ParamField>

At least one of `q`, `brand`, `note`, `family`, or `priceRange` is required on every request, including requests that pass `cursor`.

## Example Request

```bash
curl -G https://api.noteboxd.com/v1/fragrances \
  -H "Authorization: Bearer nb_live_YOUR_KEY" \
  --data-urlencode "note=oud" \
  --data-urlencode "limit=20"
```

## Example Response

```json
{
  "data": [
    { "id": "initio-oud-for-greatness", "name": "Oud for Greatness", "brand": "Initio" },
    { "id": "montale-black-aoud", "name": "Black Aoud", "brand": "Montale" }
  ],
  "nextCursor": "eyJ..."
}
```

Pass `nextCursor` back as `cursor` to fetch the next page. When `nextCursor` is `null` or absent, that page is the last one. There is no `page` parameter and no total count.

## Response Fields

| Field | Type | Description |
|---|---|---|
| `data` | array | Fragrance summaries for this page. |
| `data[].id` | string | Fragrance id. Use it with other fragrance endpoints. |
| `data[].name` | string | Display name. |
| `data[].brand` | string | Brand or house name. |
| `nextCursor` | string \| null | Cursor for the next page, or `null` when there are no further matches. |

## Rate Limit Headers

Every response includes the following headers:

| Header | Description |
|---|---|
| `X-RateLimit-Limit` | Maximum number of requests allowed in the current window. |
| `X-RateLimit-Remaining` | Number of requests remaining in the current window. |
| `X-RateLimit-Reset` | Unix timestamp at which the rate limit window resets. |

<Note>
  Each item is a summary. For notes, accords, and perfumer attribution, call [Get Fragrance](/api-reference/fragrances/get) with the `id`.
</Note>
